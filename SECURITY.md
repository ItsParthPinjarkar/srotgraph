## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue, please report it responsibly.

### How to Report

1. **Do not** open a public issue for security vulnerabilities
2. Send an email to [INSERT SECURITY EMAIL] with the details
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested fixes (optional)

### What to Expect

- **Acknowledgment**: We will acknowledge receipt within 48 hours
- **Assessment**: We will assess the vulnerability and determine its severity
- **Fix**: We will work on a fix and release it as soon as possible
- **Disclosure**: We will coordinate disclosure with you after the fix is available

### Security Best Practices for Contributors

When contributing to SrotGraph:

1. **Never hardcode secrets or API keys** in source code
2. **Use environment variables** for all sensitive configuration
3. **Validate all user input** before processing
4. **Keep dependencies updated** and monitor for security advisories
5. **Follow principle of least privilege** when implementing features

### Security Advisories

For information about security updates, watch the repository's "Security" tab or subscribe to our security mailing list.
